# AI 使用与验证记录

## 开发阶段

- 工具：Codex；由用户指定使用 DeepSeek 作为产品运行时模型。
- AI 辅助范围：产品流程、规则模型、前后端代码、数据库结构、异常处理、测试、界面和提交文档。
- 人类决策：用户选择题目 1，并提供完整要求；用户指定 DeepSeek，密钥由用户自行保存。
- 关键人工可复核依据：源代码、规则版本、持久化检查记录、原始测试报告及操作视频。
- 未把开发阶段 AI 产出的设计推断当成用户调研结果、市场事实或金融判断。

## 产品运行阶段

- 模型用途：自然语言到规则草案；不参与每轮数据判断，不执行金融操作。
- 提示词版本：`rule-compiler-v1.0`，全文在 `lib/radar/compiler.ts`。
- 官方文档查阅日期：2026-10-07；默认模型 `deepseek-flash`。
- 设置：JSON 输出，`temperature=0`，关闭 thinking，输出上限 1800 tokens，25 秒超时。
- 限制：temperature=0 不保证准确性或重复运行完全一致；结构化格式也不保证意图正确。
- 必须经用户确认草案；服务端再次校验规则字段、类型、数值范围、标的和条件数量。
- 失败策略：明确展示备用模板解析，不伪称模型输出；关键条件不清楚时请求澄清。

## 已实际完成的验证

1. 35 项规则与解析测试：原始结果在 `unit-test-results.txt`。其中模型 HTTP 429、非法 JSON 结构/字段以及成功返回等使用模拟响应，不能证明真实接口可用。
2. 23 项本地 API / D1 集成测试：原始结果在 `local-integration-test-results.json`。实际覆盖服务端保存、访问隔离、任务执行、去重冷却、恢复与版本。
3. TypeScript 静态检查已执行；最终功能修正已通过静态检查和构建。
4. 23 项生产 API 集成测试通过，详见 `production-integration-test-results.json`。
5. 真实浏览器操作与首次外部定时调用已验证，详见 `浏览器与上线验证.md`。

真实 DeepSeek 调用仍待用户填入密钥；目前不能宣称真实模型调用已验证。
